# CLASS 8A — Rumah Digital 8A

Website kelas 8A dengan desain coklat klasik/vintage, pencarian siswa, jadwal piket, visi-misi, struktur organisasi, dan galeri.

## Cara menjalankan
1. Extract ZIP ini.
2. Buka `index.html` di Chrome/Edge/Firefox.
3. Semua aset foto sudah berada di folder `assets`.

## Catatan struktur organisasi
PDF struktur organisasi tidak dapat diproses dari file yang tersedia pada percakapan ini, jadi bagian struktur dibuat sebagai template yang mudah diedit. Jika kamu kirim screenshot/gambar halaman struktur, bagian tersebut bisa disesuaikan dengan desain dan nama yang tepat.
